💡 为什么之前的"一键获取"不好用

小红书把登录会话的 Cookie（web_session）设置成了 HttpOnly 模式。

这是浏览器的安全机制——标记为 HttpOnly 的 Cookie，网页里的 JavaScript 代码（包括书签栏小工具）完全读取不到。

但开发者工具（F12 → Application → Cookies）可以完整显示所有 Cookie，包括 HttpOnly 的。所以用开发者工具复制是最可靠的方法。
