🍠 小红书 Cookie 提取指南

5步拿到 Cookie JSON，填入系统即可管理你的小红书账号

1

在浏览器登录小红书

用 Chrome 或 Edge 打开小红书官网并登录你要管理的账号。

务必确保：当前浏览器已经登录了你的小红书账号。
如果还没登录，先去 xiaohongshu.com 完成登录。
https://www.xiaohongshu.com
🏠 小红书 · 首页
在地址栏确认是 xiaohongshu.com，且右上角显示你的头像（已登录）
↓
2

打开开发者工具

按下键盘上的 F12 键（或 Ctrl+Shift+I / Cmd+Option+I）。

浏览器右侧或底部会打开一个面板，这就是开发者工具。

💡 Mac 用户： 如果 F12 没反应，按 Command + Option + I
💡 笔记本用户： 可能需要同时按 Fn + F12
https://www.xiaohongshu.com
Elements Console Application Network Sources
按 F12 后出现的 DevTools 面板
↓
3

切换到「Application」标签 → 找到 Cookies

在开发者工具顶部标签栏，点击 「Application」（应用标签）。

在左侧菜单栏找到 「Storage」→「Cookies」，点击展开，然后点击 「https://www.xiaohongshu.com」。

✅ 确认：右侧应该能看到一列 key/value 形式的 Cookie 数据，包含 a1、web_session、x-user-id 等字段。
↓
4

一键导出 Cookie 为 JSON

在 Console（控制台） 标签页里运行一行代码，直接把 Cookie 转成 JSON 复制到剪贴板。

方法 A（推荐）：在 Console 里粘贴以下代码

// 粘贴后按回车，自动复制 JSON 格式的 Cookie 到剪贴板
copy(JSON.stringify(
  Object.fromEntries(
    document.cookie.split('; ').map(c => c.split('='))
  )
)) // 执行后直接去粘贴即可
✓ 运行后 · 什么都不会显示，但已经复制到剪贴板了。
打开任意文本编辑器按 Cmd+V 检查，应该看到类似这样的内容：
{"a1": "187#####", "webId": "xxxx", "web_session": "xxxx", ...}

方法 B：在 Application 面板右键导出

5

粘贴到系统 + 填用户 ID

回到 社交媒体管理平台（http://127.0.0.1:8765）→ 账号管理 → 添加账号 → 选小红书。

📋 需要填写的两个字段：

① 小红书店 Cookies (JSON)
  ← 粘贴刚才复制的那段 JSON（以 { 开头，} 结尾）

② 用户 ID
  ← 粘贴 669c4ab40000000024022bcd
你的用户 ID：在你之前发的链接里：
https://www.xiaohongshu.com/user/profile/669c4ab40000000024022bcd
✅ 填好后点击「确认添加」，系统自动验证，完成！
验证通过后账号出现在列表里，就可以用它发布内容了

💡 小提示

  • Cookie 有时效性，如果账号状态变成"异常"，重新拿一次 Cookie 更新即可
  • 每个账号需要单独拿它自己的 Cookie（登录哪个账号，拿到的就是哪个的）
  • 最好用 Chrome 或 Edge 浏览器操作，Safari 开发者工具界面不太一样
  • 拿 Cookie 时不要关闭小红书页面，保持登录状态
